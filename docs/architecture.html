1人が仕様を書く → 2チャットで承認を頼む → 3Kiro が承認マーカーを作る → 4Hook が invoke_sdlc.py を起動 → 5dev-agent が AWS で実装・テスト → 6成果物を projects/ に取り込む → 7人がレビュー・テスト
