# スラッグ変換ツール 要件定義

## 概要

任意の文字列を、URL に使える短い識別子（スラッグ）に変換する関数を追加する。外部サービスに依存しない純粋関数として実装し、単体テストだけで正しさを検証できるようにする。

## ユーザーストーリー

### US-1: タイトルからスラッグを作る
開発者として、記事のタイトルなどから URL 用の識別子を自動で作りたい。手で書くと表記がぶれるため。

## 受入基準

1. WHEN `slugify("Hello World")` を呼ぶ
   THEN `"hello-world"` を返す

2. WHEN 大文字を含む文字列を渡す
   THEN すべて小文字にして返す

3. WHEN 英数字以外の文字（空白・記号）が1文字以上続く
   THEN その並び全体を1つのハイフン `-` に置き換える（`"a  --  b!!c"` → `"a-b-c"`）

4. WHEN 結果の先頭または末尾がハイフンになる
   THEN 先頭と末尾のハイフンを取り除く（`"  Hello!  "` → `"hello"`）

5. WHEN アクセント付きのラテン文字を含む
   THEN アクセントを外した英字にする（`"Café Crème"` → `"cafe-creme"`）

6. WHEN ラテン文字に変換できない文字（日本語など）を含む
   THEN 記号と同じく区切りとして扱う（`"abc日本語def"` → `"abc-def"`）

7. WHEN 空文字列、または英数字を1文字も含まない文字列を渡す
   THEN 空文字列 `""` を返す（エラーにしない）

8. WHEN `slugify(None)` を呼ぶ
   THEN `ValueError` を発生させる

9. WHEN 文字列以外の型（数値・リスト等）を渡す
   THEN `TypeError` を発生させる

## スコープ外

- 日本語などのローマ字化（区切りとして扱うだけ）
- 長さの上限
- 重複するスラッグの回避
